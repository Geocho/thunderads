The Brief

Hoper is six businesses wearing one logo.

Hoper started as helicopter transfers. It's becoming something much bigger: a search-and-compare platform, scheduled point-to-point flights, aerial experiences, private charter, and routes that don't exist anywhere else. Six products. Six different problems. One brand.

The brief wasn't a campaign. It was the layer underneath every campaign: a communication architecture that lets one brand sell six things without ever sounding confused, generic, or off-pillar.

The Problem

One message can't sell
six products.

Most travel brands pick one line and repeat it. Hoper couldn't. A ferry-replacement message aimed at a private charter buyer is noise. A price-led message shown to someone who doesn't know helicopters are an option is wasted spend. Same brand, same week, six audiences, five mindsets, eight places they could be standing. Repetition wasn't an option. The brand needed a system.

The Approach

Every execution answers three questions.

We built the brand around a single rule. Before any line is written, any visual is briefed, any euro is spent, the execution has to answer three things. Get all three right and the message is automatically on-brand, on-funnel, and in-context.

01
Pillar. What are we selling?
Six product pillars, each solving a different problem: Search/OTA, Scheduled, Experiences, Private, Special Routes, and the Universal brand layer. Pillars never mix inside one execution. Ever.
02
Stage. What is the user thinking?
A five-step funnel of mindset: Interrupt, Reframe, Simplify, Convert, Normalize. The stage decides how much you say. Top of funnel carries no price and no CTA. Only Convert is allowed to ask for the sale.
03
Context. Where are they standing?
Port, Airport, City, Island, Search, Social, Retargeting, CRM. Context turns a generic line into an instantly relevant one. "Skip the ferry" lands at a port. It's invisible anywhere else.
04
The persona sets the angle, not the line
Time-sensitive wants speed. Explorer wants the view. Planner wants clarity. Premium wants control. Same route, four motivations. Persona tunes the angle inside the pillar; it never overrides the system.

The Funnel

Same person. Different moment. Different message.

Five stages of mindset. Each one decides how much the execution is allowed to say. We move people one step at a time, never skipping.

Stage 01Interrupt
User thinks"Wait… what?"
We doBreak the pattern. Headline only, no price, no CTA.
Stage 02Reframe
User thinks"That's smarter."
We doChange the perception. Headline plus contrast.
Stage 03Simplify
User thinks"I get it."
We doRemove complexity. Route plus duration, still no price.
Stage 04Convert
User thinks"I'll do it."
We doTrigger action. The only stage allowed price and a CTA.
Stage 05Normalize
User thinks"I'll do it again."
We doBuild the habit. Identity only, brand over offer.

Why It Matters

A campaign runs out. A system compounds.

The deliverable wasn't a set of ads. It was the architecture that makes every future ad correct by default. New routes, new destinations, new pillars slot in without a rebrief. A media buyer, a designer, and a copywriter who have never met can each open the matrix and produce work that is unmistakably Hoper.

Right message. Right moment. Right product. Not as a slogan, as a system that enforces it.
